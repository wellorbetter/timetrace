# 你的电脑时间都去哪了？用 TimeTrace 给自己记一笔「时间账」

> Steam 会告诉你游戏时长，但浏览器、IDE、剪辑软件各占多少？锁屏待机算不算？
> 一个 100% 本地运行、开源免费、解压即用的 Windows 时间统计 + 日记工具。

---

最近一直在折腾自己电脑上时间的去向：Steam 能查到某款游戏玩了多久，但我的浏览器、代码编辑器、视频软件到底各占了多少？挂机、锁屏、合盖睡觉的时间又该怎么算？总不能天天手动记。

于是我用 Rust + Flutter 手搓了一个 Windows 桌面应用——**TimeTrace**。现在已经开源，并发布了第一个 Release（v0.1.0）。

【图1：柱状图 · 各应用活跃时长一目了然】

## 它能做什么

**1. 自动统计每个应用的真实活跃时长**
前台切到哪个应用就记哪个，支持应用级归一化：Edge 就是 Edge，英雄联盟就归英雄联盟，不会混成一团。

**2. 空闲 / 锁屏 / 睡眠不背锅**
挂机、锁屏、睡眠的时间会被自动识别为「空闲」，不算进任何应用的活跃时长，统计才真实。

**3. 数据仪表盘 + 日历联动**
柱状图、饼图、24 小时时段分布、当日汇总、应用分布……都在一个轮播里；左边日历选哪一天，右边数据跟着切。

【图2：饼图 · 时间占比】

**4. 24h 时段分布，看自己什么时候最专注**
一天 24 个小时里哪个小时干得最多，还能自定义起止小时区间。

【图3：当日汇总 · 24h 活跃热力 + 使用记录】

**5. 应用分布：每个应用都列全**
哪个应用用了多久，点开还能看页面级会话。

【图4：应用分布】

**6. 日记：给每天留句话**
朋友圈式日记，支持 Markdown 和图片，草稿自动保存，按天分组折叠。统计 + 日记放一起，年底回顾很有感觉。

【图5：时段分布】

**7. 常驻托盘，随时呼出**
缩小到托盘不占地方，右键菜单快速控制，不打扰打游戏。

## 为什么值得一试：隐私优先

所有数据只存在本地 SQLite，**无网络、无遥测、不上传任何东西**。Windows 原生体验，解压即用，不需要安装。

## 关于开发

全程 vibe coding：前期用 DeepSeek V4 Flash + Pi 快速搭原型，后期切换到 Codex 做性能与交互优化（轮播动画、范围缓存、空闲/锁屏统计都来回调了好几轮）。对 AI 辅助开发感兴趣的朋友，可以翻翻仓库的提交记录。
